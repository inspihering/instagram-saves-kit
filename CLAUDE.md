# Instagram Saves to Notion - Setup Kit

This folder is a ready-to-run kit. It is NOT yet configured for you.

**When the user asks to install, set up, or configure this project, follow `INSTALL.md`
from top to bottom.** Rules:

- Work one step at a time. Do not skip steps or batch them.
- Ask the user for one credential or one choice at a time. Never invent or guess credential
  values, API tokens, resource IDs, or configuration choices. If you do not have a value, ask.
- Where INSTALL.md says to create an external resource (for example a Notion database), first
  check whether a matching one already exists in the user's connected account and reuse it.
  Create a new one only if none exists.
- Never commit the user's credentials. `config.json` and other secret files are already
  gitignored; keep them that way.

If the user has not asked to set anything up yet, tell them: to begin, just say
"set this up for me".
